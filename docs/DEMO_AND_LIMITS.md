## 3. 한계

| 구분 | 내용 |
|---|---|
| 아직 안 됨 | **위험 알림**: 시스템 연결 설정이 있어야 하고 지금은 연결 실패 알림만 나옵니다. **실제 회사 시스템 데이터**로 기록·기기·세션·로그인 정보를 보는 것 |
| 확인 불가로 남은 것 | **SDP 서버 연결 성공 여부**(설정 없이 실행 중이라 `SDP 미연결`만 확인), **AI 게이트웨이 연결·AI 설명·조치 집행·OSV 실제 조회**, **도움정보의 실제 클립보드 복사**(내장 브라우저가 거부해 안내 표시까지만 확인) |
| 모의로만 확인 | 항목별 권한 부족·시간 초과 오류 화면. 이 PC에서는 모든 항목이 일반 권한으로 읽혀 실제 재현을 못 했습니다 |
| 사람이 해 보지 않음 | 다른 사람이 브라우저 화면에서 카드·버튼·키보드를 써 본 결과, ZIP으로 받기, Node `v22`·`v23`. 친구는 서버 실행과 API 응답까지만 확인했습니다 |
| 성질상 한계 | CPU는 약 0.5초 순간 평균, 디스크는 앱 폴더가 있는 드라이브만, Windows 전용, 추이는 새로고침하면 사라짐, 서버 파일을 스타터 업데이트하면 추가한 API가 사라질 수 있음 |
| 연습 중 발견해서 고친 점 | 기본 실행의 「보안 기록」 조회 실패 화면에도 `값 출처: [내 PC에서 잰 값]`이 붙던 문제를 고쳤습니다. 이제 값 출처 줄은 기록 조회가 성공했을 때만 나오고, 실패·불러오는 중·확인 불가에는 나오지 않습니다(모의 점검 11건과 화면에서 확인) |

안내 화면의 「이벤트 기록 일부 확인 불가」는 예시입니다. 이 PC에서는 System·Application 기록 건수가 모두 읽혔고 읽지 못한 항목이 없었습니다.

## 5. 같은 결과를 다시 만드는 순서

5. 제출 직전에 `git status`로 변경이 없는지 보고 `git rev-parse HEAD`로 40자리 번호를 다시 확인, `git ls-remote origin refs/heads/main`이 같은 번호인지 확인
