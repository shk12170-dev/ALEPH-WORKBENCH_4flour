# 다이브 실행 안내 한 장 (처음 보는 사람용)

이 안내만 보고 앱을 켜서 첫 화면까지 확인합니다. 이 앱은 **Windows 전용**입니다(3일차 기능이 Windows 도구를 씁니다). 설치할 외부 프로그램은 Node.js뿐이고 `npm install`은 필요 없습니다. 비밀번호·키·토큰은 필요 없고 입력하지도 않습니다.

## 1. 준비물 확인

PowerShell을 열고 아래를 실행합니다.

```powershell
node -v
```

- `v24`로 시작하면 됩니다. 수업 기준은 `v24.19.0`이고, `v24.20.0`에서 실제로 실행해 확인했습니다(두 PC에서 같은 결과). 실행 도구는 `v22`~`v24`를 허용하지만 `v22`와 `v23`에서는 확인하지 못했습니다.
- `node`를 찾을 수 없다고 나오면 https://nodejs.org 에서 LTS를 설치하고 PowerShell을 **새로 열어** 다시 확인합니다.

## 2. 앱 폴더 받기

둘 중 하나를 고릅니다. 이미 앱 폴더가 있으면 이 단계는 건너뜁니다(기존 폴더는 지우거나 옮기지 않습니다).

- Git이 있으면: `git clone https://github.com/shk12170-dev/ALEPH-WORKBENCH_4flour.git`
- Git이 없으면: 위 주소를 브라우저에서 열고 **Code → Download ZIP**을 받아 압축을 풉니다. 압축을 풀면 같은 이름의 폴더가 한 번 더 들어 있을 수 있으니, 3번에서 `package.json`이 보이는 안쪽 폴더로 이동합니다.

## 3. 앱 폴더로 이동하고 확인

```powershell
cd <앱 폴더 경로>
Get-Location
dir package.json
```

- `Get-Location`은 지금 PowerShell이 어느 폴더에 있는지 보여 줍니다. 앱 폴더 경로와 같아야 합니다.
- `package.json` 파일이 목록에 보이면 맞는 폴더입니다. 안 보이면 폴더가 틀렸습니다(아래 「막혔을 때」 1번).

## 4. 앱 켜기

```powershell
npm start
```

화면에 `케셰브 연결 확인: http://127.0.0.1:5189`처럼 `케셰브 연결 확인:`으로 시작하는 한 줄이 나오면 켜진 것입니다. 정상일 때 나오는 줄은 이것뿐이고, 그 뒤로 새 줄이 없는 것도 정상입니다. **이 PowerShell 창을 닫지 마세요**(닫으면 앱이 꺼집니다).

## 5. 첫 화면 확인

브라우저에서 `http://127.0.0.1:5189`를 엽니다. 이 주소는 내 PC에서만 열립니다.

| 보이는 것 | 의미 |
|---|---|
| 오른쪽 위 `연결 없음`, 빨간 박스 5줄 | **정상입니다.** 회사 시스템에 연결하지 않은 기본 실행이기 때문이며 오류나 침해가 아닙니다 |
| 브라우저 개발자 도구나 `/api/me`를 직접 열었을 때 `HTTP 503`, `ENGINE_NOT_CONNECTED`, `disconnected` | **정상입니다.** 위와 같은 이유(연결 없음)이며 앱이 고장 난 것이 아닙니다 |
| 학생 칸 맨 위 「핵심 기능 3가지」 | 기록 보기, 내 PC 상태, 위험 알림과 지금 되는지 여부 |
| 「PC 상태 다시 조회」 버튼 | 누르면 이 PC의 CPU·메모리·디스크 값과 잰 시각이 나옵니다 |
| 「연결·기록 다시 조회」 버튼 | 누르면 약 10초 뒤 네트워크, 방화벽, Windows 경고·오류 건수가 나옵니다(읽기만 하며 설정은 바꾸지 않습니다) |
| 「내 PC 실시간 확인(6칸)」 | 「내 PC 확인」을 누르면 6칸이 채워집니다. 「10초마다 확인」은 체크한 동안만 자동으로 읽습니다(기본 꺼짐) |
| 「내 PC 점검 화면 열기 ↗」(`/pc`) | PC 점검만 따로 보는 화면입니다. 「7개 항목 중 n개 조회」, 이전 조회 대비, 조회 추이 표가 나옵니다 |
| 「점검 기록 열기 ↗」(`/checks`) | 「점검 실행」을 누르면 앱이 자기 서버에 읽기 요청만 보내 사례별로 대조합니다. 지금은 「일치 11 + 미실행 5」가 정상입니다 |
| 「연습 경보 시연 열기 ↗」(`/practice`) | 공식 연습 경보 158건을 판단 모듈에 넣은 결과(block 53 · alert 52 · record 53)가 나옵니다. **[예시 화면 · 설명용 값]이며 이 PC의 실제 탐지가 아닙니다** |
| 개발자 도구 콘솔의 빨간 `503` 5줄(`/api/me` 등) | **정상입니다.** 첫 화면이 열릴 때 제공 코드가 연결 없음 상태의 API를 불러서 생깁니다. `/pc`, `/checks` 화면에서는 생기지 않습니다 |

값 표시는 두 가지로 구분됩니다.
- **[내 PC에서 잰 값]**: 이 PC에서 방금 읽은 값입니다.
- **[예시 화면 · 설명용 값]**: 실제 조회 결과가 아닌 설명용 값입니다. 예제 모드(`npm run demo`)나 안내 문서의 그림에 나옵니다.

## 6. 끄기와 다시 켜기

- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl+C`
- 다시 켜기: 4번의 `npm start`
- 새 버전을 받은 뒤 `/pc`나 `/checks`가 열리지 않으면(찾을 수 없음 404) 서버를 끄고 다시 켜세요. 서버는 켤 때 화면 목록을 읽습니다

## 막혔을 때

| 증상 또는 오류 문구 | 원인 | 할 일 |
|---|---|---|
| `npm error Missing script: "start"` | 앱 폴더가 아닌 곳(예: `C:\Users\이름>`)에서 실행함 | 3번으로 돌아가 `cd`로 앱 폴더에 이동하고 `Get-Location`, `dir package.json`으로 확인한 뒤 다시 실행. ZIP이면 안쪽 폴더인지도 확인 |
| `Error: listen EADDRINUSE: address already in use 127.0.0.1:5189` | 5189 포트를 이미 다른 것이 쓰는 중 | ① 브라우저에서 `http://127.0.0.1:5189`가 **열리면** 이미 앱이 켜진 것이니 새로 켜지 말고 그대로 씁니다(다시 켜려면 켜 둔 창에서 `Ctrl+C` 후 `npm start`). ② **안 열리면** 기존 서버가 방금 종료된 경우가 있으니 몇 초 기다렸다가 `npm start`를 다시 실행합니다. ③ 그래도 같으면 `netstat -ano \| findstr :5189`로 어떤 프로세스 번호(PID)가 쓰는지 읽기만 하고, 그 결과를 AI에게 보여 주세요(프로세스를 마음대로 끄지 않습니다) |
| 앱 폴더에서 `npm`을 실행했더니 PowerShell이 스크립트 실행을 거부함 | PC의 PowerShell 실행 정책 | 정책을 바꾸지 말고 `npm.cmd start`로 실행합니다(같은 명령입니다). 이 PC에서는 이 오류가 나지 않아 직접 재현하지는 못했습니다 |
| `git clone`에서 `Recv failure: Connection was reset` | 앱이 아니라 네트워크 문제로 GitHub에 연결하지 못함 | 네트워크를 바꾸거나 잠시 뒤 다시 시도, 안 되면 2번의 Download ZIP 방법 사용 |
| `node` 또는 `npm`을 찾을 수 없음 | Node.js 미설치 또는 PowerShell을 새로 열지 않음 | 1번 참고 |
| `v21` 이하 또는 `v25` 이상으로 표시됨 | 지원 범위 밖의 Node 버전(실행 도구는 22~24만 허용) | 가능하면 `v24` LTS를 설치 |
| 브라우저에서 연결이 안 됨 | 서버가 꺼졌거나 PowerShell 창을 닫음 | 앱을 켠 창이 열려 있는지 확인하고, 닫았다면 4번을 다시 실행. 창은 닫지 않기 |
| 「PC 상태 다시 조회」나 「연결·기록 다시 조회」에 `확인 불가`가 보임 | 권한, 시간 초과, 서버가 꺼짐 등 | 화면에 적힌 「다음에 할 일」을 따릅니다. 앱은 어떤 설정도 바꾸지 않습니다 |
| 그 밖의 오류 | | 새 폴더를 만들지 말고 아래 「AI에게 보낼 문구」에 오류 문구 전체를 그대로 붙여 보내세요 |

## 오류가 났을 때 AI에게 보낼 문구

아래를 복사해 빈칸을 채워 AI에게 보냅니다. **키·비밀번호·토큰은 붙이지 마세요.**

```text
다이브 앱 실행 중 문제가 발생했습니다.

1. 현재 진행 단계: (예: Node.js 확인 / 앱 폴더 이동 / npm start / 브라우저 접속)
2. 사용 환경: Windows (버전: ), Node.js 버전(node -v): , 실행한 명령:
3. 발생한 오류 문구: (오류 메시지 전체를 그대로 복사)
4. 현재 상황: (어떤 화면이 나오는지)

원인이 안내에 있는지 코드에 있는지 먼저 알려 주고, 초보자도 이해할 수 있게 단계별로 설명해 주세요.
기존 파일이나 설정을 삭제하거나 바꾸지 않는 안전한 방법부터 알려 주세요.
```
